ENGLISH SPRINT — WEBSITE HỌC TIẾNG ANH 60 NGÀY (A2 → B1)
======================================================

Nguồn nội dung: Lo_trinh_tieng_Anh_A2_den_B1_60_ngay_v3.xlsx

MỞ WEBSITE
1. Giải nén gói ZIP.
2. Nhấp đúp index.html để mở trong Google Chrome hoặc Microsoft Edge.
3. Vào "Cài đặt & dữ liệu" để chọn ngày bắt đầu, chế độ 40 / 60 / 90 phút.
4. Chọn "Học hôm nay", làm từng bước và bấm "Đã làm xong" ở mỗi hoạt động.
5. Cuối buổi: ghi thời lượng, điểm (khi có), lỗi thường gặp và đánh dấu ngày hoàn thành.
6. Dùng "Lộ trình 60 ngày" để chọn bất kỳ ngày nào.

CÁC TÍNH NĂNG
- Tổng quan tiến độ, mục tiêu theo tuần.
- 60 buổi học; 293 hoạt động chi tiết theo Excel V3.
- Thời lượng tự điều chỉnh 40 / 60 / 90 phút/ngày.
- Mở bài học British Council, DailyDictation, các nguồn IT.
- Đếm giờ trong từng hoạt động.
- Thư viện tài liệu, hướng dẫn phương pháp, thẻ Anki, 6 prompt AI.
- Lưu điểm Listening / Speaking (và Reading / Writing vào ngày kiểm tra).
- Xuất / nhập JSON sao lưu toàn bộ tiến độ.

LƯU Ý
- Website chạy bằng HTML + JavaScript thuần, không cần cài ứng dụng, không cần Excel.
- Nội dung và dữ liệu ban đầu nằm trong file index.html; các trang học bên ngoài cần mạng.
- Điểm số trên website là nhật ký tự nhập, KHÔNG phải chứng chỉ CEFR.
- Tiến độ lưu trong bộ nhớ của trình duyệt trên chính thiết bị của bạn. Không đồng bộ tự động.
- Nên dùng "Cài đặt & dữ liệu" > "Xuất dữ liệu JSON" mỗi tuần để sao lưu.
- Bản web không thay đổi file Excel V3 gốc.
- Để sử dụng liên tục nhiều thiết bị, có thể đưa index.html lên dịch vụ host tĩnh (GitHub Pages, Vercel), nhưng dữ liệu vẫn lưu riêng theo trình duyệt nếu chưa có backend.
